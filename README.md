# Matribox Remote

Web app per comandare da tablet o telefono la pedaliera multieffetto **Sonicake Matribox** (prima versione, QME-50), collegata via USB.

- Cambio preset (utente e fabbrica) e scaletta
- Editor dei 9 blocchi: on/off, modello, parametri, footswitch, ordine della catena
- Salvataggio e rinomina dei preset
- Drum machine con tap tempo
- Registrazione dell'audio USB in WAV

Funziona in Chrome (PC o Android) aperto da `https://` o `localhost`, con il Matribox collegato via USB (su Android con cavo OTG).

Progetto non ufficiale, non affiliato con Sonicake. Il protocollo MIDI è stato ricavato osservando l'editor ufficiale.
